A. STATISTICAL PROCEDURES REQUESTED FROM STATISTICIAN:
   1. Test of Normality (Shapiro-Wilk Test) on the Difference Scores:
      - Variable 1: Hesitation_Diff (ms)
      - Variable 2: Error_Diff (Count)
      - Variable 3: Accuracy_Gain_Pct (%)
   2. Paired-Samples t-Test (Two-Tailed, df = 19, alpha = .05):
      - Pair 1: PreTest_Hesitation_ms vs. PostTest_Hesitation_ms
      - Pair 2: PreTest_Error_Count vs. PostTest_Error_Count
      - Pair 3: PreTest_Accuracy_Pct vs. PostTest_Accuracy_Pct
   3. Effect Size Computation via Cohen's d (or Hedges' g):
      Formula: d_z = Mean_Diff / SD_Diff

B. MATHEMATICAL FORMULAS USED:
   - Difference Score: D_i = Post_i - Pre_i (or Pre_i - Post_i for latency/error reductions)
   - Mean Difference: D_bar = (sum(D_i)) / n
   - Standard Error of Difference: SE_D = s_D / sqrt(n)
   - Paired t-Statistic: t = D_bar / SE_D
   - 95% Confidence Interval: D_bar +- (t_crit * SE_D)  [where t_crit(19, 0.05) = 2.093]
   - Cohen's d: d = D_bar / s_D
